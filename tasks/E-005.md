# E-005 — Dodaj wybór celu, warstw i wag

Cel: Wykonać podstawowy scenariusz użytkownika dla jednej i wielu warstw.

Zakres: apps/web/src/controls/ i stan konfiguracji.

Orientacyjny nakład: 1–2 h. To oszacowanie planu, nie zmierzony czas.

## Kroki

1. Pobierz profile i dostępne cechy z katalogu; zachowaj rozróżnienie Mars/Moon i regionu.
2. Dodaj aktywowanie kryteriów i dodatnie wagi z czytelną normalizacją.
3. Dodaj przycisk analizy / debounce i walidację pustego zestawu oraz niedostępnych kryteriów.

## Kryteria odbioru

- [x] Jedna aktywna cecha trafia do requestu bez dodatkowych ukrytych kryteriów.
- [x] Widoczność mapy jest poza modelem kryteriów; zmiana metadanych widoczności nie zmienia requestu ani wag.
- [x] Request spełnia kształt schematu; UI uruchamia analizę wyłącznie przyciskiem, nie podczas ruchu suwaka.
- [x] Live wybiera wyłącznie dostępny dataset roli `earth_search`, Synthetic — `fixture_only`; brak lub wieloznaczność zwraca czytelny błąd.
- [x] Test regresyjny sprawdza dostępny `validation` przed `earth_search`, brak/wieloznaczność roli i wybór Synthetic.

## Sprawdzenie

Scenariusze jednej, trzech, zerowej liczby cech i przełączenia profilu z inną dostępnością.
