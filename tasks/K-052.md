# K-052 — Połącz web z regionalnym API przez jawne CORS

Cel: umożliwić przeglądarce korzystanie z trybu live E-006, gdy web i API działają pod różnymi originami, bez awarii żądań i bez przejścia na dane syntetyczne.

Zakres: `apps/api/main.py`, `apps/api/tests/test_api_contract.py`, `apps/api/README.md`. Nie edytuj aktywnej ścieżki `apps/web/` Eweliny.

## Kroki

1. Dodaj jawny, konfigurowalny allow-list originów przez `TERRA_ANALOG_CORS_ORIGINS`, z ograniczonymi originami localhost dla lokalnego serwera Vite jako wartością domyślną.
2. Dopuść wyłącznie metody i nagłówki potrzebne katalogowi/profilom/wyszukiwaniu; nie włączaj wildcard ani credentials.
3. Dodaj sprawdzenia dozwolonego originu, niedozwolonego originu i preflightu POST oraz opisz ustawienie `VITE_API_BASE_URL` i serwera API.

## Kryteria odbioru

- [x] Dozwolony dokładny origin dostaje nagłówki CORS dla katalogu i wyszukiwania; preflight POST akceptuje `Content-Type`.
- [x] Niedozwolony origin i wildcard nie otrzymują dostępu; polityka nie używa cookies ani credentials.
- [x] Realny regionalny przebieg API zachowuje kontrakt, wersję profilu/datasetu i jawny regionalny scope.
- [x] Dokumentacja podaje odtwarzalne uruchomienie dwóch lokalnych serwerów oraz konfigurację osobnego originu produkcyjnego.

## Sprawdzenie

Uruchom testy API kontraktu na rzeczywistym katalogu i regionalnym wyszukiwaniu oraz testy preflight/CORS. Sprawdź dozwolony i niedozwolony origin. Uruchom `git diff --check`. Nie twierdź, że przeglądarka przeszła pełny przepływ bez rzeczywistego wywołania z originu web.
