# E-034 — Pilny odbiór CORS regionalnego API K-052

> Pilny odbiór po E-035 i po zakończeniu bieżącej aktywnej pracy. Nie przerywaj rozpoczętego E-010.

Cel: potwierdzić, że przeglądarka może bezpiecznie odczytać prawdziwe regionalne odpowiedzi API z jawnie dozwolonego originu.

Zakres: exact `review_ref` i PR #98: `apps/api/main.py`, testy API oraz `apps/api/README.md`. Nie rozszerzaj review na ogólny audyt API ani nie twierdź, że zweryfikowano pełny przepływ w przeglądarce.

## Warunek startu

K-052 jest przekazane do review na dokładnym refie powyżej. Przed startem potwierdź bieżący head PR #98 oraz dostępność exact ref. Jeżeli branch się zmienił, zatrzymaj review i uzgodnij aktualizację `review_ref` z Kamilem.

## Kroki

1. Sprawdź exact ref, pliki zmienione w PR #98 oraz zgodność konfiguracji z allow-listą dokładnych originów.
2. Skontroluj odrzucanie wildcardów i niepoprawnych originów, brak credentials, metody/nagłówki preflightu oraz brak `Access-Control-Allow-Origin` dla obcego originu.
3. Sprawdź test regionalnego POST na rzeczywistym pakiecie i zgodność instrukcji uruchomienia dwóch serwerów oraz konfiguracji wdrożeniowej.
4. Opublikuj krótki raport z decyzją i dowodami. Blokuj odbiór tylko przy błędnej granicy dostępu, uszkodzeniu API/danych albo fałszywym twierdzeniu; drobne uwagi zapisz jako follow-up.

## Kryteria odbioru

- [ ] Raport potwierdza exact SHA i aktualny head/base PR #98.
- [ ] Konfiguracja CORS nie używa wildcardów ani cookies/credentials i nie dopuszcza nieznanych originów.
- [ ] Dozwolone katalog/wyszukiwanie oraz preflight `POST` z `Content-Type` są sprawdzone; regionalny request zachowuje prawdziwy dataset i jawny scope.
- [ ] Raport rozróżnia test transportu API od uruchomionego przepływu w przeglądarce.
- [ ] Wynik review jest opublikowany w remote; ewentualna poprawka jest przypisana Kamilowi.
