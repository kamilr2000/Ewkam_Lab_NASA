# E-036 — Preserve map-layer state when selecting pixels and rerunning

## Cancellation reason

K-055 reproduced two visibility defects on pre-fix PR #96 ref f6eb210e91d389afc865cc10d4a7f0509c4d155a: with ranked markers turned off, selecting another ranked pixel displayed all ten markers; changing criteria and rerunning reset all three layer switches.

This task duplicated the P0 correction already reopened under E-035. The fix was implemented in 8d2fc1cd99db37442021eee4775d2855be839662 and integrated into origin/main through PR #96, squash SHA f82ebabe175dd63dad12fca9cfd06f91b5bb6c5a. K-055 subsequently verified the corrected behaviour with real regional data. No separate E-036 implementation is required.

## Original acceptance scope

1. Keep markers hidden after selecting a different ranked pixel while the marker switch is off.
2. Preserve all layer settings when criteria change, the old result clears, and a new analysis is run.
3. Add regression checks for pixel selection and a full rerun.
4. Confirm layer visibility does not change query criteria, ranking, or analysis ID.
5. Pass the web tests, production build, and diff check.

See the completed [E-035](E-035.md), [K-055 browser review](K-055.md), and [K-054 map review](K-054.md) for implementation and evidence.
