# E-009 — Przygotuj build web do wspólnego wydania

Cel: Dostarczyć gotowy frontend do I-004.

Zakres: apps/web/build i konfiguracja wdrożenia tej aplikacji.

Orientacyjny nakład: 1 h. To oszacowanie planu, nie zmierzony czas.

## Kroki

1. Zbuduj finalny web, sprawdź URL API, bazową ścieżkę i trasy statyczne.
2. Zapisz rzeczywiste polecenia build/test i sposób podłączenia pod wspólny origin.
3. Sprawdź, czy żadne sekretne dane nie trafiły do bundla i czy źródła podkładu są opisane.

## Kryteria odbioru

- [ ] Build finalnej wersji przechodzi i łączy się z rzeczywistym API.
- [ ] Można uruchomić wydanie według instrukcji bez środowiska development.
- [ ] Przekazanie zawiera ograniczenia i wymagania wobec backendu.

## Sprawdzenie

Uruchomiony build produkcyjny na reprezentatywnych przepływach; nie tylko serwer development.

## Przebieg i dowody

Jeszcze nie rozpoczęto. Przed implementacją opublikuj osobny commit IN PROGRESS w origin/main: status in_progress, agent, data i gałąź. Potwierdź zdalną rezerwację. Każdą poprawkę commituj i wysyłaj po synchronizacji oraz rozwiązaniu rzeczywistych konfliktów. Zapisz sprawdzenia, wysłane SHA/PR i ograniczenia; done dopiero po integracji do origin/main. Przy blokadzie wpisz przyczynę i niewysłane zmiany. Nowe zadania dodaj według [szablonu](TEMPLATE.md) i również opublikuj w remote.
