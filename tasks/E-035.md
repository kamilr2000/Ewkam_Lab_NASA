# E-035 — Dodaj czytelny podkład mapy i przełączane warstwy wyników

> Pilne dla demo o 22:00 — pierwsze zadanie Eweliny po zakończeniu już rozpoczętej aktywnej pracy. Nie przerywaj E-010.

Cel: na prawdziwym regionalnym wyniku pokazać teren na mapie z rozpoznawalnym podkładem oraz umożliwić włączanie i wyłączanie warstw bez zmiany lub ukrywania rankingu.

Zakres: `apps/web/src/map/AnalysisMap.tsx`, powiązany styl i testy oraz krótki update `apps/web/README.md`. Zachowaj istniejący wybór pomiarów w panelu kryteriów i ponowne uruchomienie analizy E-006; nie buduj drugiego scoringu w przeglądarce.

## Kroki

1. Dodaj domyślny podkład uliczny OpenStreetMap z przezroczystą warstwą komórek wynikowych oraz warstwą markerów pikseli.
2. Dodaj niezależne, widoczne przełączniki podkładu OSM, komórek wyniku i markerów; przełączniki mapy zmieniają wyłącznie widok, nie ranking ani analizę.
3. Zachowaj wybór aktywnych pomiarów i wag w kryteriach E-006. Po zmianie kryterium poprzedni wynik nie może pozostać jako wynik nowego zapytania; po ponownym uruchomieniu zachowaj jawny profil, wersję datasetu i region.
4. Przetestuj na żywym regionalnym wyniku w istniejącym lokalnym przepływie demo. Potwierdź, że OSM jest widoczne pod półprzezroczystymi wynikami, a marker Top 10 i opis zachowują ten sam `analysis_id`.
5. Nie dodawaj zdjęć satelitarnych bez istniejącego źródła, licencji i wymaganych danych dostępowych. OSM-owe kafle pokazuj wyłącznie dla widoku żądanego przez użytkownika; nie pobieraj ich hurtowo ani z wyprzedzeniem.

## Kryteria odbioru

- [ ] Live mapa pokazuje rzeczywisty OSM street basemap z wynikiem nadal czytelnym nad nim; attribution `© OpenStreetMap contributors` jest stale widoczne i linkuje do strony licencji.
- [ ] Podkład, komórki wynikowe i markery mają niezależne dostępne klawiaturą przełączniki; ukrycie warstwy jest tylko prezentacją i nie zmienia API query/rankingu.
- [ ] Panel zachowuje wybór aktywnych pomiarów i wagi; ich zmiana czyści poprzedni wynik, a ponowne obliczenie używa wybranego body/profile/datasetu/regionu.
- [ ] Manualny live przebieg potwierdza prawdziwe dane, nowy `analysis_id` po ponownym obliczeniu oraz powiązanie mapy/szczegółu z tym ID.
- [ ] `npm test --prefix apps/web`, `npm run build --prefix apps/web` i `git diff --check` przechodzą. README podaje źródło podkładu i ograniczenia.
- [ ] Nie wprowadzono niezweryfikowanego providera satelitarnego ani twierdzenia, że OSM jest warstwą naukową.

## Zasady OSM

Użyj oficjalnego HTTPS endpointu `https://tile.openstreetmap.org/{z}/{x}/{y}.png`; widoczną atrybucję utrzymuj poza kontrolami, które można schować. Nie ustawiaj restrykcyjnego `Referrer-Policy`, nie omijaj cache HTTP i nie dodawaj prefetch/offline. Dla demo wykonuj tylko zwykłe żądania kafli widocznych w viewport.

Źródła: [OpenStreetMap Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) oraz [OpenStreetMap Copyright and License](https://www.openstreetmap.org/copyright).
