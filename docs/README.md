## Evidence and change policy

Descriptions of implemented behaviour must match integrated code and exact review evidence. Keep plans distinct from shipped features, real observations distinct from synthetic fixtures, and product behaviour distinct from submission preparation. Do not alter scientific values, source provenance, licence statements, review outcomes, or historical task evidence as part of an English-language edit.
