# Submission guide

The project team prepares the product description, demo, sources, licence notes, and evidence. Only Kamil or Ewelina may complete the formal NASA Space Apps submission. An agent must not submit the form, send an equivalent API request, make attestations, or accept terms on a person's behalf. Task I-006 is human-only.

## Before using jury materials

1. Confirm the event, team account, team members, local deadline, and current form requirements in the team's account.
2. Use only the current, reviewed project description and demo. Match each statement about implemented features, datasets, scale, and results to source evidence.
3. Verify the public project and demo links in a signed-out browser. A private repository or local file is not a public link.
4. Confirm data, software, map, and media attributions and licence terms.
5. Describe the score as a configured terrain-similarity index. State the regional scope, missing-data policy, scale, limitations, and features that remain planned.
6. Provide disclosures required by the event rules, including accurate AI/SI assistance disclosure. Keep the public statement consistent with the source-backed internal register.
7. The submitting team member personally reviews required declarations and terms, submits the form, and retains the confirmation URL and local timestamp.

## Current evidence boundary

The integrated application provides a regional MVP. Global search is unavailable, and no public deployment or anonymous link should be claimed unless separately verified. Refer to the current jury-package status in submission/README.md, the local event-guide snapshot in sources/03-submission.md, and human-only task I-006. Preparation, a saved draft, or a local demo file is not proof of formal submission.
